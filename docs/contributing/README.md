# 贡献者指南

面向代码贡献者。项目级开发约定以仓库根目录 [AGENTS.md](../../AGENTS.md) 为唯一来源，本目录只做面向贡献者的补充与索引。

## 规划内容

| 文档 | 内容 |
| --- | --- |
| `development-setup.md` | 开发环境与构建 |
| `testing.md` | 测试与 CI |
| `code-style.md` | 格式化与风格 |
| `review-process.md` | 评审流程与粒度 |
| `release-process.md` | 发布流程 |

## 文档编写约定

- **命名**：目录小写单词或 kebab-case；文件名 kebab-case，不含与目录重复的前缀。
- **元数据**：工程文档（architecture / design / decisions / rfcs）在文首用表格声明编号 / 状态 / 责任人 / 源码基线。
- **模板**：教学 = 目标→前置→步骤→验证；操作 = 适用场景→步骤→校验；参考 = 签名/字段表；解释 = 背景→结构→权衡。
- **文档类型边界**：设计文档回答「是什么 / 怎么做」，ADR 回答「当时为什么这么选、放弃了什么」，RFC 回答「打算怎么改、待定」，三者互不替代。
