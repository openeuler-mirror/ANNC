# 架构决策记录（ADR）

记录对 ANNC 架构有长期影响的决策：上下文、选择、后果与放弃的备选。**已做决策，只增不改。**

## 现状

现有 ADR 位于 [../ADR/README.md](../ADR/README.md)（索引）与 [../ADR/decisions.md](../ADR/decisions.md)（详情），计划迁入本目录并拆分为**一决策一文件**。

## 约定

- 命名：`NNNN-slug.md`，编号单调递增、不复用。
- 状态：`proposed → accepted → (implemented) → deprecated / superseded`。
- 何时新增：见现有 [../ADR/README.md](../ADR/README.md) 的「何时添加 ADR」。
- 索引：迁移后由本目录 `README.md` 维护索引表。
